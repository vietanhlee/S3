\subsection{Sensitivity to the Split Unit}
Table~\ref{tab:split_ablation} compares KNN performance on frozen Swin-Large embeddings between random image split and CEGS-Split. Random image split yields a mean KNN accuracy of $0.9581$; CEGS-Split yields $0.9087$, a difference of $4.94$ absolute percentage points. Macro-F1 decreases from $0.9493$ to $0.8858$. Because the feature extractor and KNN classifier are identical across conditions, this experiment demonstrates that the split unit can substantially alter evaluation results.

Maximum cross-split cosine similarity decreases from $0.9161$ to $0.8999$ under CEGS-Split, while mean cosine similarity changes only slightly. This is consistent with random image split producing a subset of train--test pairs that are closer in representation space; however, cosine values alone do not establish whether those pairs share a common source. A conclusion about leakage requires examining the intersection of \texttt{specimen\_id}s across splits and verifying the manifest. Under a conservative reading, these results establish only that scores from the same pipeline are sensitive to how images are grouped into split units.

CEGS-Split is not designed to make the task arbitrarily easier or harder. It defines a different evaluation question: recognizing images from specimens that were not seen during training. The 4.94~percentage-point difference should not be generalized as an expected level of overestimation for all image-level split datasets; it is the observed difference on S3 under the current feature extractor and KNN configuration.

\subsection{Implications for Representation Learning Benchmarks}
These results indicate that benchmarking loss functions is only informative when the split is locked before any training decisions are made. With a common CEGS-Split, metric learning and self-supervised methods can be compared using retrieval metrics, clustering quality, and macro-F1. Full result reporting should include the seed, checkpoint selection rule, per-split specimen counts, and run-to-run variance. A single score on a random image split is insufficient to separate the contribution of model architecture from the contribution of split structure.

\subsection{Limitations}
First, the CEGS-Split results are based on a single locked split; confidence intervals for the protocol itself cannot be computed without multiple group-disjoint configurations. Second, generalization beyond S3---to different imaging devices, surface conditions, or specimen origins---has not been validated against an external test set. Third, the reliability of specimen-level splitting depends directly on manifest completeness. These limitations motivate the release of versioned manifests, multiple group-disjoint splits, and an out-of-domain test set in future work.
