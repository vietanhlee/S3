\section{Experimental Configuration}

\subsection{S3 Dataset and Analysis Unit}
The S3 dataset consists of macro-scale cross-sectional images of 18 wood species from 5 genera: \textit{Afzelia}, \textit{Dalbergia}, \textit{Guibourtia}, \textit{Pterocarpus}, and \textit{Sindora}. Each species is organized in multiple subdirectories; in the version used here, each subdirectory corresponds to one physical specimen. Records identified only to genus level are excluded from supervised training. Before applying SCDP to a new version of S3, the correspondence between subdirectories and specimen identifiers must be verified in the manifest rather than assumed from directory names.

Fig.~\ref{fig:eda_split} shows the per-species distribution of images and specimens after CEGS-Split. Reporting both quantities is necessary: additional images of a specimen improve surface coverage but do not increase the number of independent units available for evaluating generalization.

\subsection{Split Protocol and Comparison}
We compare two evaluation configurations. \emph{Random Image Split} partitions images with per-species stratification but places no constraint on images from the same source appearing in different splits. \emph{CEGS-Split} uses \texttt{specimen\_id} to assign all images from a source group to a single split (train, validation, or test), and performs a data audit to check class balance and flag cross-split pairs with high cosine similarity. Both configurations use the same frozen feature extractor and KNN procedure in the split comparison; observed differences are therefore attributable to the split unit rather than to model architecture.

Random Image Split is performed with three seeds (42, 123, 456). CEGS-Split is reported as a single locked split for reproducible benchmarking. Because only one CEGS-Split configuration is reported, all quantitative comparisons with random splits describe benchmark sensitivity rather than a statistically powered test. Future work should release multiple group-disjoint splits or use group cross-validation when specimen counts allow.

\subsection{Classification Baseline Training}
The classification baseline uses ConvNeXt-Tiny~\cite{convnext} initialized from ImageNet pre-trained weights. Extracted features are passed to a linear classifier head and optimized with Focal Loss ($\gamma=2.0$, $\alpha=0.25$) to account for class frequency and difficulty. Approximately 90\% of backbone layers are frozen. The optimizer is AdamW with initial learning rate $10^{-4}$, weight decay $10^{-2}$, and a Cosine Annealing scheduler for up to 100 epochs; early stopping with patience 50 is applied on validation loss.

Data augmentation is applied only to the training set and includes rotation, random resized crop, mild color jitter, Gaussian blur, and random erasing. These transforms are chosen to simulate variation in macro-photography conditions without obscuring vessel pores or wood rays. All normalization statistics, checkpoint selection, and hyperparameter decisions are made on the training and validation sets; the test set is withheld until final reporting.

\subsection{Representation Learning Methods}
On the same locked manifest and split, the benchmark covers four distance-based metric learning losses (Contrastive, Triplet, Semi-hard Triplet, and Angular) and four self-supervised methods (SimCLR, BYOL, SimSiam, and Barlow Twins). The objective of the benchmark is not to identify a universally optimal loss function but to assess whether conclusions about relative model performance are stable when data conditions are fixed and thoroughly audited.

\subsection{Evaluation Metrics}
For closed-set classification, we report accuracy, per-species precision, recall, and F1, together with macro-F1 and weighted-F1. Macro-F1 is prioritized when class sizes are unequal. For embeddings, we report retrieval metrics Recall@$k$, Precision@$k$, and mAP; macro averages and harmonic means are reported to prevent dominant classes from masking per-class performance. The harmonic mean with a small stabilizing constant $\epsilon=0.01$ is:
\begin{equation}
\mathrm{HM}=\frac{C}{\sum_{c=1}^{C}\frac{1}{m_c+\epsilon}},
\end{equation}
where $m_c$ is the metric value for species $c$ and $C$ is the number of species.

Embedding structure quality is supplemented by Silhouette, Davies--Bouldin, Calinski--Harabasz, Dunn index, and normalized mutual information (NMI). These clustering metrics do not replace recognition performance but assess the quality of learned representations from an unsupervised perspective.

\subsection{Split Audit Metrics}
In addition to recognition performance, we record the specimen count in each split, the number of shared \texttt{specimen\_id}s across splits (which must be zero), and cross-split cosine similarity from the reference feature extractor. In Table~\ref{tab:split_ablation}, cosine values are the mean and maximum over train--test image pairs; they serve as a diagnostic indicator of inter-split proximity rather than a direct measure of leakage. Any image flagged by the embedding audit must be cross-referenced with the manifest before drawing final conclusions.
