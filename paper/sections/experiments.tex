\section{Experimental Setup}

To evaluate specimen-level data leakage and benchmark partitioning paradigms, we conduct controlled experiments on the S3 macroscopic wood species dataset. This section details the dataset governance, the feature extraction setup, the evaluation protocol, and experimental controls.

\subsection{The S3 Macroscopic Wood Dataset}
The benchmark dataset comprises macroscopic cross-sectional images of 18 wood species spanning 5 botanical genera: \textit{Afzelia} (4 spp.), \textit{Dalbergia} (5 spp., CITES Appendix II listed), \textit{Guibourtia} (3 spp.), \textit{Pterocarpus} (4 spp.), and \textit{Sindora} (2 spp.). Each subfolder in the dataset maps to an immutable physical specimen block ($g_i$). Two raw categories lacking physical harvest logs (\textit{Pterocarpus sp.} and \textit{Peltogyne pubescens}) were excluded under governance rules, leaving 18 taxonomically verified species. Target split ratios are set to **Train 60\% / Val 20\% / Test 20\%**.

\subsection{Feature Extraction and Zero-Training KNN Protocol}
To isolate dataset partitioning performance from neural network training stochasticity (such as random weight initialization, optimizer state variance, or epoch termination choices), we adopt a **Zero-Training Nearest-Neighbor ($1$-NN) Evaluation Protocol**:

\begin{enumerate}[label=\textbf{\arabic*:}, leftmargin=*]
\item \textbf{Deep Feature Backbone}: Deep feature representations are extracted using \texttt{tf\_efficientnetv2\_m\_in21k}~\cite{efficientnetv2}, a state-of-the-art Convolutional Neural Network pre-trained on ImageNet-21k.
\item \textbf{Embedding Extraction}: Macro images of resolution $224 \times 224$ pixels are mapped to 1280-dimensional feature vectors $\boldsymbol{f}_i \in \mathbb{R}^{1280}$. Feature vectors are $L_2$-normalized: $\phi(x_i) = \frac{\boldsymbol{f}_i}{\|\boldsymbol{f}_i\|_2}$.
\item \textbf{1-NN Classification}: For each test sample $x_{\text{test}} \in \mathcal{D}_{\text{Test}}$, a $1$-Nearest Neighbor classifier assigns the species label of the closest training sample under Cosine distance:
\begin{equation}
\hat{y}(x_{\text{test}}) = y\left( \arg\max_{x_{\text{train}} \in \mathcal{D}_{\text{Train}}} \phi(x_{\text{test}})^T \phi(x_{\text{train}}) \right).
\end{equation}
\item \textbf{Multi-Seed Replication}: All experiments are evaluated across 5 independent random seeds (\texttt{[42, 123, 456, 789, 2024]}). Summary tables report mean performance and standard deviation ($\text{Mean} \pm \text{Std}$).
\end{enumerate}

\subsection{Controlled Experimental Paradigms}
We evaluate the streamlined suite of six splitting protocols spanning five distinct paradigms:
\begin{itemize}
\item \textbf{\texttt{PP0\_Stratified\_Random}}: Baseline Naive Random Image Split (Maximum Leakage).
\item \textbf{\texttt{PP8\_StratifiedGroupKFold}}: Baseline Standard Grouping (Physical Subfolder Isolation).
\item \textbf{\texttt{PP4\_Hierarchical\_Clustering}}: Unsupervised Dendrogram Ward Linkage Clustering.
\item \textbf{\texttt{PP7\_Adversarial\_Validation}}: Adversarial MLP Discriminator Outlier Isolation.
\item \textbf{\texttt{PP10\_DataSAIL\_Specimen}}: DataSAIL Integer Linear Programming (Specimen Level).
\item \textbf{\texttt{PP13\_DataSAIL\_Meta\_Selector\_Multi\_Objective\_SA}}: Multi-Objective Simulated Annealing Meta-Selector ($k^N$ Search Space).
\end{itemize}

Statistical significance between the baseline \texttt{PP0} and candidate protocols is evaluated using Welch's $t$-test ($p$-value) and Cohen's $d$ effect size:
\begin{equation}
d = \frac{\bar{X}_1 - \bar{X}_2}{s_{\text{pooled}}}, \quad s_{\text{pooled}} = \sqrt{\frac{s_1^2 + s_2^2}{2}}.
\end{equation}
