\section{Experimental Setup and S3 Case Study}

To validate the proposed Specimen-Centric Data Protocol (SCDP) and quantify specimen-level data leakage, we conduct controlled experiments on the S3 macroscopic wood species benchmark. This section details the dataset characteristics, existing partitioning baselines, evaluation protocols, and deep vision architectures.

\subsection{The S3 Wood Benchmark Dataset}
The S3 dataset comprises high-resolution macroscopic cross-sectional images of 18 wood species spanning 5 botanical genera: \textit{Afzelia} (4 spp.), \textit{Dalbergia} (5 spp., CITES Appendix II listed), \textit{Guibourtia} (3 spp.), \textit{Pterocarpus} (4 spp.), and \textit{Sindora} (2 spp.). Each image subdirectory maps to a distinct physical wood specimen block. Following SCDP governance, two raw categories lacking specimen provenance logs (\textit{Peltogyne pubescens} and an unassigned \textit{Pterocarpus sp.}) were excluded, leaving 18 taxonomically verified species. \subsection{Comparative Analysis of Data Partitioning Protocols}
To evaluate the effectiveness of CEGS-Split, we compare it against four existing dataset partitioning protocols commonly used across machine learning literature:

\begin{enumerate}[label=\textbf{Protocol \arabic*:}, leftmargin=*]
\item \textbf{Random Image-Level Split (R-Split)}: Uniform random sampling over image files without physical specimen isolation (simulating prevailing ad-hoc computer vision workflows). Images harvested from the same physical block $S_k$ co-occur across training and test sets, causing severe specimen-level data leakage.

\item \textbf{Naive GroupKFold Split (G-Split)}: Standard group-disjoint splitting by \texttt{specimen\_id} (Scikit-Learn `GroupKFold`). While G-Split enforces specimen isolation, it completely ignores per-species class balance, resulting in severe sample size imbalance and missing minority classes in validation or test splits.

\item \textbf{Stratified GroupKFold Split (SG-Split)}: Extends GroupKFold to balance class proportions while maintaining specimen isolation. However, SG-Split ignores feature-space representation density, often placing highly similar specimen pairs across split boundaries.

\item \textbf{Spatial / Distance Blocking (S-Split)}: Groups specimens based on Euclidean feature distance thresholds. S-Split prevents spatial proximity across splits but suffers from over-clustering, reducing split diversity.

\item \textbf{CEGS-Split (Proposed SCDP Governance)}: Evaluates seven distinct feature-space allocation strategies per species (Section~\ref{sec:cegs_split}) combined with cross-split cosine auditing, guaranteeing 100\% specimen isolation, preserving exact per-species balance, and maximizing evaluation difficulty.
\end{enumerate}

\subsection{Vision Backbones and Baseline Architectures}
We evaluate four representative deep vision architectures spanning distinct representation paradigms:
\begin{itemize}
\item \textbf{ConvNeXt-Tiny}~\cite{convnext}: Pure convolutional backbone ($28.6\text{M}$ parameters) incorporating $7\times 7$ depthwise separable convolutions and inverted bottlenecks.
\item \textbf{Swin-Large}~\cite{swin}: Hierarchical Vision Transformer ($197\text{M}$ parameters) computing self-attention within shifted local windows.
\item \textbf{EfficientNetV2-M}~\cite{efficientnetv2}: NAS-optimized convolutional backbone ($54.1\text{M}$ parameters) using Fused-MBConv layers.
\item \textbf{ResNet-50}~\cite{resnet}: Classic 50-layer residual convolutional baseline ($25.6\text{M}$ parameters).
\end{itemize}

\subsection{Training Protocol and Implementation Details}
All classification models are trained using **Focal Loss**~\cite{focal} ($\gamma = 2.0, \alpha = 0.25$) to handle class imbalance across wood species. Models are optimized using AdamW ($\beta_1 = 0.9, \beta_2 = 0.999$, weight decay $10^{-4}$) with a cosine annealing learning rate scheduler (initial learning rate $10^{-4}$, minimum $10^{-6}$) for 50 training epochs. Input images are resized to $224 \times 224$ pixels and normalized using ImageNet channel statistics. Standard data augmentations (random horizontal/vertical flips, random rotations up to $15^\circ$, and color jitter) are applied strictly to training partitions.
